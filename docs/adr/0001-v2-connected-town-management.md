# Require connectivity for V2 town changes

Status: accepted product boundary, September 28, 2026; not yet implemented.

Each cadet must be able to continue one town across devices. Initial V2 requires a connection for town mutations and reward claims, while construction and production advance during absence and reconcile on return. This trades full offline editing for avoiding divergent offline spending and worker assignments across devices. The user accepted this boundary; backend, identity, and synchronization technology remain undecided. It does not disable existing offline combat by itself.
