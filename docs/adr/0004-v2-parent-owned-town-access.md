# Parent-owned cadet access with one active management device

Status: accepted product boundary, September 29, 2026; not implemented.

One parent account manages multiple cadet profiles without requiring separate child email addresses. Parent controls are protected, and a town has one active management device at a time with explicit handoff. The user accepted this boundary to provide cross-device continuity without simultaneous town editing. Authentication vendor, account recovery, device authorization, and legacy local-profile migration remain to be designed.
