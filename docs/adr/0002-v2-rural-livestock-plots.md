# Reserve larger outskirts plots for livestock

Status: accepted product boundary, September 28, 2026; not yet implemented.

Ordinary town buildings remain freely placeable on predefined town plots. The user accepted larger rural plots along predefined outskirts roads for Chicken Coops, Dairy Barns, and Pig Farms, deliberately making livestock an exception to the earlier any-building-on-any-plot rule. This accommodates visible animals and farm space while retaining the dense, walkable town center. Rural dimensions, utility costs, and transition planting are still to be designed.
