# Project brief

Math on Mars is a personal-use browser game: a space marine survives alien-slime waves and answers Kindergarten–Grade 5 math questions between waves to earn upgrades.

## Confirmed scope

- Home play with adult-assisted setup and local cadet profiles.
- Selected practice tracks for grades K–5. Grade 6 is retired; older profiles default to Grade 5.
- Desktop, phone, and tablet play. Production phones/tablets require landscape; portrait shows a rotate prompt and pauses the mission.
- One automatically firing weapon with reusable, combinable ammo types.
- A walkable base camp hub. Entering the portal starts a **new** arena mission; leaving to camp or reloading drops in-progress mission state. Cadet settings and practice history persist.

The owner wants the game built without an educator assignment, learner recruitment, formal studies, or evidence-gathering release gates. Focused implementation checks still apply.

Permanent armory, accounts/cloud sync, classroom management, and additional subjects remain deferred. A V2 walkable town is exploratory only; see [V2_TOWN_BUILDER_PLAN.md](../V2_TOWN_BUILDER_PLAN.md).
