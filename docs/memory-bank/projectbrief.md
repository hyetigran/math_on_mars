# Project brief

Math on Mars is a personal-use browser MVP: a space marine survives alien-slime waves and answers math questions between waves to earn upgrades.

## Confirmed scope

- Home play with adult-assisted setup, local profiles, and repeatable core missions.
- Selected practice tracks for every grade K–6.
- Desktop, phone, and tablet play, including portrait and landscape touch controls.
- One automatically firing weapon with reusable, combinable ammo types.
- Local saves and resume, including interrupted quizzes and corrections.

The owner wants the game built without an educator assignment, learner recruitment, formal studies, or evidence-gathering release gates. Focused implementation checks still apply.

Hub, permanent armory, accounts/cloud sync, classroom management, and additional subjects are deferred. See [GAME_PLAN.md](../GAME_PLAN.md) for the complete scope and tuning defaults.
