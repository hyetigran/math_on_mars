# Game typography

Self-hosted variable WOFF2 fonts, normal style, weights 400–800, Latin and extended Latin subsets:

- Oxanium — geometric display headings, buttons, HUD numerals. https://fonts.google.com/specimen/Oxanium
- Atkinson Hyperlegible Next — reading text, math questions, inputs. https://fonts.google.com/specimen/Atkinson+Hyperlegible+Next

Downloaded from Google Fonts on 2026-09-18. Both are distributed under the bundled SIL Open Font Licenses. Runtime loading is local and works with the offline pack.

The archived Space Mission sheets are raster concept artwork, not a font. Oxanium is the runtime approximation; it is not represented as an exact conversion of that lettering. Runtime declarations and role assignments are in `src/typography.css`.
