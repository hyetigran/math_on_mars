The JSON files are the runtime bank. Numbers are fixed; only selection order is shuffled by mission and grade. Successive waves traverse that grade's shuffled deck, cycling after exhaustion. A wave of up to 20 questions contains distinct items. New missions can revisit prior items. Existing saved quizzes keep their original content.

Each item records the public source URL, unit, section, problem, optional part, and changes. `source.original` is a normalized source excerpt or summary, not a promise of verbatim transcription. Some open-ended tasks are narrowed to a single numerical response; some stories receive an app-authored question. Hints, worked explanations, skill names and multiple-choice distractors are app-authored. No publisher images, logos or gated teacher solutions are included. Standards are recorded only where explicitly verified on the source page.

An independent audit recalculated 111 direct expressions/equations and reviewed the remaining story and rounding answers. Automated tests cover provenance, fixed selection, no repeats before deck exhaustion, and correct-answer/distractor invariants. This is not educator validation or a standardized assessment.

## Parent progress and limitations

This is a selected-skill starter bank, not complete grade coverage. Saved first attempts, corrections, source IDs and skills support reporting how much was practiced and how accurately. Completing X questions alone does not demonstrate mastery. Repeated items and multiple-choice guessing must be distinguished from first-attempt success on unfamiliar problems and retained learning over time. No validated mastery score is introduced by this bank.

The default remains eight seconds per question combined into one wave timer; Settings allows more time. Story problems and multi-step tasks may require a slower pace.

## Adding items

Use the cited first edition and verify its license; other IM editions/resources have different terms. Preserve source quantities, record every adaptation, independently solve the question, and verify the source locator. Keep stable item IDs, supply an appropriate distractor denominator, and check all answer formats. Run the bank tests and the quiz browser checks. Do not silently fall back to generated problems or claim unverified standards alignment.
